# Achronix Semiconductor Corporation

> Achronix is a Silicon Valley fabless semiconductor company (founded 2004, Santa Clara,
> California) that designs high-performance FPGAs, embedded FPGA (eFPGA) IP and PCIe
> accelerator cards for data center, networking, 5G, automotive, test-and-measurement and
> AI-inference workloads. Achronix sells silicon, licensable IP and desktop EDA software —
> it does not publish a public web API, an OpenAPI/AsyncAPI/GraphQL contract, an SDK, a
> developer portal, an MCP server or an A2A agent card. This file is generated by API
> Evangelist from the company's public website; it is not published by Achronix.

## Products

- [Speedster7t FPGAs](https://www.achronix.com/product/speedster7t-fpgas): 7nm FPGA family with a 2D network-on-chip, machine learning processors, GDDR6 memory and 400G Ethernet.
- [Speedcore eFPGA](https://www.achronix.com/product/speedcore): embedded FPGA IP licensed for integration into customer ASICs and SoCs.
- [VectorPath Accelerator Cards](https://www.achronix.com/product/vectorpath-accelerator-cards): PCIe accelerator cards, including the VectorPath 815 built on the 7t1500 FPGA.
- [ACE Design Tools](https://www.achronix.com/product/fpga-design-tools-achronix): the Achronix integrated Design Environment, the desktop toolchain for synthesis, place-and-route and timing closure.
- [JESD204C IP](https://www.achronix.com/product/jesd204c-ip): converter-interface IP core.
- [Chiplets](https://www.achronix.com/chiplets): FPGA chiplet offerings for disaggregated designs.
- [Achronix AI Console](https://www.achronix.com/Achronix_AI_console): AI-inference evaluation environment, available only via a 30-day evaluation request form.
